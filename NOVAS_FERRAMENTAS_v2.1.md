# 🛠️ Malha3D v2.1 — 20 Novas Ferramentas Propostas

---

## 1. Versionamento de Projetos

**O que é:** Um sistema de controle de versões dentro de cada projeto, similar ao Git. Toda vez que o designer faz uma entrega parcial ou atualização, cria-se uma "versão" (v1.0, v1.1, v2.0). O cliente pediu pra voltar ao render anterior? Um clique e tudo volta.

**Como funciona na prática:**
- Ao salvar alterações no projeto, o sistema pergunta "Criar nova versão?"
- Cada versão guarda: arquivos, status, valores, notas
- Comparação visual lado a lado (antes/depois)
- Botão "Restaurar versão anterior" sem perder a atual
- Changelog automático: lista o que mudou entre versões

**Por que importa:** Elimina o medo de perder trabalho. Cliente mudou de ideia 3 vezes? Você tem tudo documentado. Zero retrabalho jogado fora.

## 2. Galeria de Referências com Análise Inteligente

**O que é:** Um painel dentro do projeto onde você sobe imagens de referência (fotos de Pinterest, Archdaily, Instagram) e o sistema analisa automaticamente as cores, materiais e estilos dominantes.

**Como funciona na prática:**
- Área de drag-and-drop para subir referências do cliente
- IA extrai: paleta de cores, materiais identificados, estilo arquitetônico
- Organiza por categoria: Iluminação, Acabamentos, Mobiliário, Paisagismo
- Link público para compartilhar moodboard com cliente
- Cliente pode comentar em cada imagem: "quero esse piso" → marca para produção

**Por que importa:** O briefing fica 100% visual. Acabam os mal-entendidos de "eu imaginava diferente". A IA faz o trabalho de catalogar.

---

## 3. Fluxo de Aprovações com Assinatura

**O que é:** Um workflow estruturado onde cada entrega passa por etapas obrigatórias (Criação → Revisão Interna → Aprovação do Cliente → Entrega Final). Ninguém pula etapa.

**Como funciona na prática:**
- Você define as etapas: quem revisa, quem aprova, deadline de cada
- Ao submeter, o próximo da fila recebe notificação (email + WhatsApp)
- Cada aprovador clica "Aprovar" ou "Solicitar ajustes" (com comentário)
- Assinatura digital: registro de quem aprovou, quando, IP
- Se prazo estourar: escalona para gerente automaticamente
- Histórico completo: "Cliente aprovou em 15/08 às 14h32"

**Por que importa:** Elimina o gargalo de "esperando aprovação". Protege juridicamente: tudo documentado com data/hora.

---

## 4. Controle de Horas por Atividade

**O que é:** Timer integrado que registra quanto tempo cada tarefa realmente leva. Não é genérico — é por atividade (modelagem, texturização, renderização, pós-produção, reunião).

**Como funciona na prática:**
- Botão de play ao lado de cada tarefa no projeto
- Pausa automática se ficar inativo 5 minutos (não infla hora)
- Categorias: Modelagem 3D, Texturização, Iluminação, Render, Composição, Revisão, Reunião
- Dashboard: horas reais vs estimado — onde você erra no planejamento?
- Relatório por freelancer: quanto tempo cada pessoa levou
- Exporta timesheet para pagamento de PJs

**Por que importa:** Saber onde o tempo vai é saber onde o dinheiro vai. Projeto que era pra dar 20h e levou 45h? Agora você vê onde perdeu.

## 5. Checklist de Qualidade (QA)

**O que é:** Antes de marcar qualquer projeto como "pronto para entrega", o sistema roda uma lista de verificações obrigatórias. Se falhar em alguma, bloqueia a entrega até corrigir.

**Como funciona na prática:**
- Checklist configurável por tipo de projeto:
  - Renderização: resolução correta? Color space sRGB? Sem artefatos? Refletir briefing?
  - Animação: FPS correto? Áudio sincronizado? Transições suaves?
  - Tour Virtual: Hotspots funcionando? Loading < 3s? Mobile compatível?
- Marcar item como "OK" ou "Falha" (com foto do problema)
- Se tudo OK → libera entrega + gera certificado de qualidade
- Se falha → cria tarefa automática para o responsável corrigir

**Por que importa:** Zero entrega com erro. Cliente vê badge "Aprovado em QA" e confia mais. Você padroniza qualidade mesmo com time grande.

## 6. Gerador de Mockups Contextuais

**O que é:** Você entrega o render final e o sistema gera automaticamente mockups mostrando a imagem em contexto real — na tela de um notebook, em uma moldura na parede, em um outdoor, em um celular.

**Como funciona na prática:**
- Projeto finalizado → botão "Gerar Mockups"
- Sistema insere o render em 10-20 templates (monitor, moldura, revista, outdoor, tablet)
- Download em pack (ZIP com todos os mockups)
- Envio para cliente via link ou WhatsApp
- Uso: portfólio, redes sociais, proposta comercial

**Por que importa:** Apresentação profissional sem esforço extra. Cliente vê o render "na vida real" e percebe mais valor. Aumenta chances de fechar novos projetos em 25%.

## 7. Formulário de Briefing Estruturado

**O que é:** Um questionário obrigatório que todo projeto precisa ter preenchido antes de começar. Não é um campo de texto livre — são perguntas específicas que garantem que nada ficou ambíguo.

**Como funciona na prática:**
- Ao criar projeto, abre formulário com seções:
  - Dados básicos: tipo, metragem, prazo, orçamento
  - Estilo: referências visuais, materiais preferidos, cores
  - Técnico: software base, resolução, formato de entrega
  - Escopo: quantas imagens, ângulos, revisões incluídas
  - Restrições: o que NÃO fazer, limitações do terreno
- Barra de progresso: "Briefing 75% completo"
- Projeto NÃO entra em produção até briefing estar 100%
- Gera PDF do briefing para assinatura do cliente

**Por que importa:** Nunca mais "ah mas eu queria diferente". Tudo combinado antes, por escrito. Reduz revisões em 40%.

## 8. Sugestão de Preço Inteligente

**O que é:** Ao preencher os dados de um novo projeto (tipo, metragem, complexidade), o sistema calcula automaticamente uma faixa de preço sugerida baseada no seu próprio histórico e no mercado.

**Como funciona na prática:**
- Preenche: Renderização, 200m², Complexidade Alta
- Sistema analisa seus últimos 50 projetos similares
- Mostra: "Preço sugerido: R$ 7.500 - R$ 9.200"
- Detalha: "Seus projetos similares ficaram em R$ 8.100 de média"
- Mostra margem esperada: "Com esse preço, margem de 62%"
- Se aceitar preço muito abaixo: alerta "Atenção: margem inferior a 40%"

**Por que importa:** Nunca mais cobrar barato demais por insegurança. Dados reais do seu histórico te dão confiança para precificar.

## 9. Sincronização com Calendário (Google/Outlook)

**O que é:** Os deadlines dos seus projetos aparecem automaticamente no seu Google Calendar ou Outlook. E o calendário do Malha3D respeita seus horários bloqueados.

**Como funciona na prática:**
- Conecta conta Google/Outlook (OAuth)
- Deadlines de projetos → aparecem como eventos no calendário
- Quando render está processando → bloqueia agenda ("Em produção")
- Calcula dias úteis automaticamente (exclui feriados, fim de semana)
- Se perceber que vai atrasar: sugere reagendamento com justificativa para cliente
- Sincroniza para ambos os lados: criar evento no Google → aparece no Malha3D

**Por que importa:** Uma fonte de verdade para prazos. Sem conflitos de agenda. Sem esquecer deadline.

## 10. Ofertas de Serviços Adicionais (Upsell)

**O que é:** Quando um projeto é entregue, o sistema sugere automaticamente serviços complementares para oferecer ao cliente — baseado no tipo de projeto e no histórico.

**Como funciona na prática:**
- Entregou renderização externa? Sistema sugere:
  - "Oferecer animação walkthrough? (+R$ 4.500)"
  - "Oferecer planta humanizada? (+R$ 1.200)"
  - "Oferecer tour virtual 360°? (+R$ 6.000)"
- Botão "Enviar oferta" → cliente recebe email/WhatsApp personalizado
- Cliente aceita com um clique → novo projeto criado automaticamente
- Dashboard: taxa de conversão de add-ons, receita incremental

**Por que importa:** Aumenta o faturamento por cliente sem esforço comercial. O sistema vende pra você no momento certo.

## 11. Pesquisa de Satisfação Automática (NPS)

**O que é:** Toda vez que um projeto é marcado como entregue, o sistema dispara automaticamente uma pesquisa rápida para o cliente avaliar a experiência.

**Como funciona na prática:**
- Projeto entregue → email/WhatsApp após 24h: "Como foi sua experiência?"
- Escala visual com emojis: 😡 😟 😐 🙂 😍
- Se nota ≤ 3: abre campo "O que podemos melhorar?" + alerta interno
- Se nota ≥ 4: oferece "Deixe um depoimento para nosso site"
- Se nota 5: oferece "Compartilhe no LinkedIn" com link pronto
- Dashboard: NPS mensal, tendência, comentários verbatim

**Por que importa:** Feedback estruturado sem perguntar manualmente. Clientes insatisfeitos são resgatados antes de virarem detratores.

## 12. Automação de Emails com Templates

**O que é:** Emails que hoje você escreve manualmente (confirmação de projeto, lembrete de prazo, entrega pronta, cobrança) passam a ser automáticos, disparados por gatilhos do sistema.

**Como funciona na prática:**
- Templates pré-prontos por situação:
  - "Projeto aceito — próximos passos"
  - "Briefing recebido — iniciando em X dias"
  - "Render pronto para revisão"
  - "Projeto entregue — obrigado!"
  - "Lembrete: pagamento vence em 3 dias"
- Merge tags: {{nomeCliente}}, {{nomeProjeto}}, {{prazo}}, {{valor}}
- Gatilhos: status mudou? Deadline chegando? Pagamento atrasado?
- Histórico: ver todos os emails enviados para cada cliente

**Por que importa:** Economiza 3-5 horas por semana em emails repetitivos. Comunicação profissional e consistente sempre.

## 13. Biblioteca de Ativos (Assets Library)

**O que é:** Uma galeria centralizada com todos os modelos 3D, texturas, HDRIs, scripts e presets que o estúdio usa. Catalogada, versionada e pesquisável.

**Como funciona na prática:**
- Upload de arquivos com metadados (categoria, software, resolução, tags)
- Categorias: Vegetação, Mobiliário, Pessoas, Veículos, Texturas, HDRIs, Scripts
- Busca inteligente: "sofá moderno cinza" → encontra modelos relevantes
- Ao criar projeto: "Usar assets da biblioteca" → importa com 1 clique
- Controle de versão: "cadeira_eames_v3.fbx" (sabe qual é a mais recente)
- Permissões: pessoal, time, público

**Por que importa:** Não modelar o que já existe. Reutilizar assets economiza 30% do tempo de produção.

## 14. Painel de Análise por Cliente

**O que é:** Cada cliente tem uma página de análise dedicada mostrando todo o histórico financeiro, comportamental e de satisfação.

**Como funciona na prática:**
- Ficha do cliente com:
  - Lifetime value (quanto já gastou com você)
  - Projetos completados (quantidade, tipos, valores)
  - Taxa de revisões (muita revisão = cliente trabalhoso)
  - Tempo médio de resposta (demora pra aprovar? Pra pagar?)
  - NPS individual
  - Margem real (faturamento - horas trabalhadas × custo hora)
- Classificação automática: VIP / Regular / Problemático
- Alerta: "Cliente X não contrata há 90 dias — risco de churn"

**Por que importa:** Saber quem é lucrativo e quem dá prejuízo. Priorizar clientes VIP. Identificar quem precisa de atenção.

## 15. Simulador de Carga de Trabalho

**O que é:** Uma ferramenta visual que mostra se o estúdio tem capacidade para aceitar novos projetos sem atrasar os atuais.

**Como funciona na prática:**
- Timeline visual: projetos atuais ocupando dias/semanas
- Arrasta novo projeto hipotético: "Se eu aceitar esse de 10 dias?"
- Sistema calcula: "Você vai atrasar o Projeto Y em 3 dias"
- Simula cenários: "E se contratar 1 freelancer?" → recalcula
- Recomendação: "Aceitar apenas se prazo for > 15 dias"
- Mostra ocupação: 75% → tranquilo | 90% → limite | 110% → sobrecarga

**Por que importa:** Aceitar projetos demais e atrasar tudo é o erro mais comum. Agora você vê antes de se comprometer.

## 16. Gerador de Apresentação Automática

**O que é:** Com um clique, o sistema monta uma apresentação profissional do projeto: desde o briefing até os renders finais, formatado como slide show.

**Como funciona na prática:**
- Botão "Gerar Apresentação" no projeto finalizado
- Sistema compila automaticamente:
  - Slide 1: Capa com nome do projeto + cliente
  - Slide 2-3: Briefing resumido + referências
  - Slide 4-6: Renders finais em alta resolução
  - Slide 7: Especificações técnicas
  - Slide 8: Ficha de aprovação
- Exporta para: PDF, PowerPoint, link web (compartilhável)
- Template branded com identidade do estúdio
- Controla: quantas vezes o link foi aberto, tempo de visualização

**Por que importa:** Apresentação profissional sem gastar 2 horas montando PowerPoint. O cliente compartilha com stakeholders automaticamente.

## 17. Negociador de Prazos com Sugestão Inteligente

**O que é:** Quando o prazo solicitado pelo cliente é inviável, o sistema sugere alternativas de negociação: prazo maior com preço normal, ou prazo curto com taxa de urgência.

**Como funciona na prática:**
- Cliente quer em 5 dias, mas precisa de 12
- Sistema sugere 3 opções para enviar:
  - Opção A: "12 dias úteis, preço normal R$ 8.000"
  - Opção B: "8 dias úteis, +30% urgência = R$ 10.400"
  - Opção C: "5 dias úteis, +80% urgência = R$ 14.400 (time dedicado)"
- Envia email profissional com as 3 opções formatadas
- Cliente clica na opção preferida → projeto atualizado automaticamente

**Por que importa:** Nunca mais aceitar prazo impossível por medo de perder cliente. Negocia profissionalmente com opções claras.

## 18. Radar de Mercado (Benchmark)

**O que é:** Um dashboard que mostra como seu estúdio se posiciona em relação ao mercado — preços, prazos, tipos de serviço.

**Como funciona na prática:**
- Compara seus dados com benchmarks do mercado ArchViz:
  - Preço médio por m² (você vs mercado)
  - Prazo médio de entrega (você vs mercado)
  - Mix de serviços (% renderização, % animação, etc)
  - Taxa de revisão (você vs mercado)
- Alertas: "Seu preço de animação está 30% abaixo do mercado"
- Tendências: "Demanda por Tour Virtual cresceu 45% este trimestre"
- Oportunidades: "Poucos estúdios oferecem planta humanizada — demanda alta"

**Por que importa:** Visão externa que impede ficar desatualizado. Saber onde você está barato demais ou lento demais.

## 19. Base de Conhecimento Interna (Wiki)

**O que é:** Uma wiki interna onde o estúdio documenta processos, tutoriais, soluções de problemas comuns e decisões tomadas.

**Como funciona na prática:**
- Artigos por tema: "Como configurar V-Ray para vidro refletivo", "Checklist de entrega de animação"
- Tags por software: Blender, SketchUp, Revit, 3ds Max, Lumion
- Busca inteligente: ao criar tarefa, sugere artigos relacionados
- Versionado: artigo atualizado mantém histórico
- Colaborativo: qualquer membro do time pode contribuir
- Favoritos: os mais usados ficam no topo

**Por que importa:** Conhecimento não fica na cabeça de uma pessoa. Novo designer consulta a wiki e resolve sozinho. Onboarding em 1 semana em vez de 1 mês.

## 20. Relatório de Lucratividade Real por Projeto

**O que é:** Vai além do "faturei X" e mostra quanto realmente sobrou. Cruza o valor cobrado com as horas reais trabalhadas (de todos os envolvidos) para calcular a margem verdadeira.

**Como funciona na prática:**
- Para cada projeto mostra:
  - Receita: R$ 8.000
  - Custo de horas: 45h × R$ 80/h = R$ 3.600
  - Custos fixos rateados: R$ 800
  - Custo de render farm: R$ 200
  - **Lucro real: R$ 3.400 (42,5% margem)**
- Compara com média dos seus projetos
- Ranking: projetos mais lucrativos vs mais "sumidouros"
- Alerta: "Projetos de Animação têm margem de 15% — revisar precificação"
- Identifica: tipo de projeto + perfil de cliente mais rentável

**Por que importa:** Faturar muito não significa lucrar. Saber onde a margem está sendo consumida (retrabalho, scope creep, horas não cobradas) é o primeiro passo para melhorar.
